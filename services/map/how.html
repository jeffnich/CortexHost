Cortex

A self-hosted second brain. Every point on the map is one memory.

The loop

Capture
Condense
Store
Reflect
Forecast
Act

Everything the owner thinks on — AI chats, coding sessions, notes — flows through an LLM distiller that keeps only the durable layer: decisions, frameworks, facts, preferences, lessons. Each becomes a one-or-two-sentence spark with a dedupe key, embedded into a private vector store. Everything you see here reads from that substrate.

What's running

Memory substrate

Qdrant, one collection, 1536-dim cosine embeddings, content-hash dedupe + near-duplicate guard.

MCP server

search / store / recall / todos, served over streamable HTTP behind a capability URL — plugged straight into the owner's AI chats.

Daily brief + foresight

A morning delta report, and weekly self-scored forecasts of which threads go dark next.

This map

UMAP projects every memory to 2D; KMeans finds the topics; a canvas renders the constellation.

Why parts are grayed out

This is the shareable demo. A classifier judges every memory personal-vs-public (erring toward private). Personal memories render as gray dots with their text stripped from the page server-side — not hidden with CSS. The full, unredacted map lives behind a separate secret URL and a passphrase.
